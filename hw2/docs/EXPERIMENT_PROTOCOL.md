# Протокол частичного воспроизведения

## Проверяемая гипотеза

Расписание 1cycle позволяет LeNet получить на MNIST сопоставимую или более высокую тестовую точность за существенно меньшее число эпох, чем стандартное обратно-степенное расписание Caffe.

## Сравниваемые режимы

| Параметр | Обычный режим | 1cycle |
|---|---:|---:|
| Эпохи | 85 | 12 |
| Число обновлений | 10 000 | зависит от обработки последнего батча; около 1 416 |
| Батч | 512 | 512 |
| Оптимизатор | SGD | SGD |
| Скорость обучения | 0,01, затем обратно-степенное снижение | 0,01 → 0,1 → 0,01 → 0,00001 |
| Инерция | 0,9 | 0,95 → 0,8 → 0,95 |
| Весовой спад | 0,0005 | 0,0005 |
| Цель из статьи | 99,03 ± 0,04% | 99,25 ± 0,03% |

## Что сохраняется одинаковым

- Набор MNIST без расширения данных.
- Архитектура LeNet из примера BVLC Caffe.
- Масштабирование значений пикселей на 1/256.
- Инициализация весов по правилу Xavier с нормировкой по числу входов.
- Функция потерь перекрёстной энтропии.
- Размер батча 512.
- Весовой спад 0,0005.
- Начальное случайное число 42.
- Оборудование и программное окружение.

## Что меняется

- Расписание скорости обучения.
- Расписание инерции.
- Число эпох.

## Собственные решения при переносе

1. Точное конечное значение скорости для MNIST в статье не указано. Выбрано 0,00001: на три порядка ниже начального значения 0,01.
2. Последние две эпохи отведены под линейное снижение от 0,01 до 0,00001.
3. Инерция на завершающем участке остаётся равной 0,95.
4. Последний неполный батч обрабатывается; `drop_last=false`.
5. Смешанная точность выключена, чтобы не добавлять ещё одно отличие от Caffe.
6. Тестовая выборка используется только для оценки, а проверка диапазона строится по обучающей функции потерь.

## Основные показатели

- Лучшая и конечная тестовая точность.
- Число эпох и обновлений.
- Чистое время обновления весов, время проверки и полное время запуска.
- Максимальная занятая память GPU.
- Кривые функции потерь, точности, скорости обучения и инерции.

## Критерий содержательного воспроизведения

Точное совпадение сотых долей процента не требуется. Метод воспроизведён содержательно, если 1cycle корректно реализован, достигает высокой точности примерно за 12 эпох и сравнивается с обычным режимом в одинаковых условиях. Все отличия от опубликованных чисел должны быть приведены в отчёте.
