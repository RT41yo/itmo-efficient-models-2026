# Протокол воспроизведения MNIST–LeNet

## Цель

Воспроизвести все шесть строк блока MNIST–LeNet из таблицы 2 статьи «Super-Convergence: Very Fast Training of Neural Networks Using Large Learning Rates».

## Набор опытов

| № | Обозначение статьи | Инерция | Эпохи | Точность статьи |
|---:|---|---|---:|---:|
| 1 | `0.01/inv` | `0.9` | 85 | `99.03 ± 0.04%` |
| 2 | `0.01/step` | `0.9` | 85 | `99.00 ± 0.04%` |
| 3 | `0.01-0.1/5` | `0.95-0.8/5` | 12 | `99.25 ± 0.03%` |
| 4 | `0.01-0.1/12` | `0.95-0.8/12` | 25 | `99.28 ± 0.06%` |
| 5 | `0.01-0.1/23` | `0.95-0.8/23` | 50 | `99.27 ± 0.07%` |
| 6 | `0.02-0.2/40` | `0.95-0.8/40` | 85 | `99.35 ± 0.03%` |

Во всех режимах используются MNIST, LeNet, размер батча 512 и весовой спад `0.0005`.

## Конфигурации

## Неизменные условия

- Набор MNIST без расширения данных.
- Архитектура LeNet из примера BVLC Caffe.
- Масштабирование пикселей на `1/256`.
- Инициализация Xavier с нормировкой по числу входов.
- Стохастический градиентный спуск и перекрёстная энтропия.
- Множитель скорости обучения `2` для смещений.
- Размер батча 512.
- Весовой спад `0.0005`.
- Смешанная точность выключена.

## Допущения переноса

1. Статья указывает для ступенчатой политики только `0.01/step`, но не сообщает интервал и коэффициент снижения. Принято снижение в 10 раз после 5000 обновлений: `step_size=5000`, `gamma=0.1`.
2. Для одноцикловых режимов после основного цикла скорость линейно уменьшается в 1000 раз относительно начальной. Точное конечное значение для MNIST в статье не приведено.
3. Продолжительности фаз выбраны непосредственно из обозначений статьи:
   - 12 эпох: `5 + 5 + 2`;
   - 25 эпох: `12 + 12 + 1`;
   - 50 эпох: `23 + 23 + 4`;
   - 85 эпох: `40 + 40 + 5`.
4. Инерция на заключительном участке остаётся равной `0.95`.
5. Последний неполный батч обрабатывается.

## Запуск

Проверка тестов:

```bash
python -m pytest -c hw2/pytest.ini hw2/tests -q
```

Поскольку режимы на 85 и 12 эпох уже могут находиться в `results`, полный сценарий запускается с пропуском готовых результатов:

```bash
python hw2/scripts/run_all.py --skip-existing
```

Эквивалентная полная команда:

```bash
python hw2/scripts/run_mnist_suite.py --skip-existing --seeds 42
```

Чтобы только перестроить сводные файлы без обучения:

```bash
python hw2/scripts/run_all.py --only-summary
```

Для трёх повторов каждой конфигурации:

```bash
python hw2/scripts/run_all.py --skip-existing --seeds 42 43 44
```

Результат с исходным случайным числом сохраняется в основном каталоге опыта. Дополнительные повторы получают суффикс `_seed43`, `_seed44` и так далее.

## Итоговые файлы

Каждый запуск сохраняет конфигурацию, окружение, историю по эпохам, расписание по шагам, итоговые показатели, веса и график.

После завершения всех опытов дополнительно создаются:

- `results/mnist_runs.csv` — показатели каждого отдельного запуска;
- `results/mnist_summary.csv` — средние значения и стандартное отклонение;
- `results/mnist_comparison.png` — единая визуализация шести строк.

Для сопоставления с таблицей статьи используется финальная, а не лучшая тестовая точность.

## Критерий воспроизведения

Точное совпадение сотых долей процента не обязательно из-за переноса с Caffe на PyTorch и неполного описания некоторых настроек. Основной проверяемый эффект — получение сопоставимого качества при существенно меньшем числе эпох и обновлений в коротких одноцикловых режимах.
