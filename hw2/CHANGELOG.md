# История изменений

## 0.3.0 — 2026-10-06

- подготовлен README с настройкой окружения, структурой и командами запуска;
- добавлен отдельный отчет по всем шести экспериментам MNIST–LeNet;
- добавлены иллюстрации диапазона скорости, общей сводки и короткого режима `1cycle`.

## 0.2.0 — 2026-10-06

- добавлены все шесть конфигураций MNIST–LeNet из таблицы 2 статьи;
- добавлено ступенчатое расписание скорости обучения;
- добавлены пакетный запуск, повторы с разными случайными числами;
- добавлены общие таблицы и график по всем режимам;
- расширены проверки конфигураций, расписаний и агрегации результатов;
- README подготовлен для окончательной документации.

## 0.1.2 — 2026-10-06

- добавлены маркеры точек на графиках одного запуска;
- графики отображают данные при короткой проверке из одной эпохи.

## 0.1.1 — 2026-10-06

- уточнена установка torchvision 0.28.0+cu129 для PyTorch 2.13.0+cu129 и Python 3.14;
- добавлена безопасная команда с `--no-deps`, которая не переустанавливает PyTorch.

## 0.1.0 — 2026-10-06

- добавлен перенос Caffe LeNet на PyTorch;
- добавлены обычное обратно-степенное расписание и линейное расписание 1cycle;
- добавлены проверка диапазона скорости, сбор метрик и построение графиков;
- добавлены конфигурации двух основных опытов и модульные тесты;
- добавлены инструкция по запуску и протокол воспроизведения.
